Vollständige Beschreibung

Bei Roche können Sie sich als Sie selbst zeigen, umarmt für die einzigartigen Qualitäten, die Sie mitbringen. Unsere Kultur fördert persönlichen Ausdruck, offenen Dialog und echte Verbindungen, in denen Sie geschätzt, akzeptiert und respektiert werden, wer Sie sind, so dass Sie sowohl persönlich als auch beruflich gedeihen können. Treten Sie Roche bei, wo jede Stimme wichtig ist.

Die Position Als Experte DevSecOps Engineer, als Experte für Softwareentwicklungssicherheit, sitzen Sie an der Schnittstelle von Software und Security Engineering. Sie sind dafür verantwortlich, robuste Sicherheits-Frameworks für die Softwareentwicklung zu entwerfen, mehrdeutige Sicherheits- und Compliance-Anforderungen zu bewältigen, komplexe Stakeholder-Landschaften zu verwalten und Nachwuchsingenieure zu betreuen. Sie werden auch mit dem Bereich Architekten bei der Definition der langfristigen Architektur für Software Engineering Sicherheitslösungen zusammenarbeiten.

Beschreibung des Gebiets

Engineering Excellence & Experience (E3) ermöglicht es Ingenieuren, Softwarepakete zuverlässig, sicher, automatisiert und konsistent in unseren verschiedenen Geschäftsbereichen zu erforschen, zu planen, zu entwerfen, zu kodieren, zu erstellen, zu testen und bereitzustellen. Dazu gehört der erleichterte Zugriff auf automatisierte, zusammensetzbare Infrastruktur, die über Infrastructure as Code (IaC) und APIs sowohl lokal als auch in der Public Cloud nutzbar ist. Innerhalb von E3 treten Sie dem Embedded Security & Testing Team bei, das sich für die Integration von Test- und Sicherheitskonzepten während des gesamten Softwareentwicklungslebenszyklus einsetzt. Insbesondere kombiniert das Code Quality, Security und Testing Engineering Team Best Practices und moderne Lösungen, um sicherzustellen, dass der gesamte generierte Code sicher und von höchster Qualität ist. Das Team bietet eine Reihe von DevSecOps-Komponenten, die für verschiedene technische Komplexitäten geeignet sind, liefert Proofs of Concept (PoCs) und unterstützt die interne Einführung während und nach der Implementierung.

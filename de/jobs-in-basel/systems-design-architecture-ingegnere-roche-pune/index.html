Die Position Senior Software Engineer — Identity & Customer Platform (CIAM)

Erfahrung: 3-5 Jahre | Stack: Java 21 · Spring Boot · Keycloak · AWS · React/TypeScript

Über die Rolle Sie erstellen und betreiben die Dienste hinter unserer Customer Identity & Access Management (CIAM)-Plattform - Authentifizierung, Autorisierung, Benutzerkontoverwaltung und die Migration von Legacy-Identitätssystemen auf Keycloak. Dies ist eine polyglotte, Multi-Repo-Umgebung: Der größte Teil des Gewichts ist Backend Java, mit sinnvollen Frontend- und Infrastrukturarbeiten. Was du tun wirst

  • Design und Ship Backend Services in Java 21 / Spring Boot (REST über Spring MVC, Jersey/JAX-RS und Spring Cloud Gateway auf WebFlux).
  • Erweitern Sie Keycloak 26 durch benutzerdefinierte SPIs, Authentifizierungsflüsse und Themes; tragen Sie zur als Code verwalteten Realm-Konfiguration bei.
  • Erstellen Sie ereignisgesteuerte und datengestützte Funktionen auf AWS - SQS / SNS, S3, Secrets Manager - mit PostgreSQL- und Liquibase-Schemamigrationen.
  • Treiben Sie die Migration von Strangler-Mustern von Legacy-Identity-Services mit Zero-Downtime-Cutovers voran.
  • Entwerfen Sie zuerst API-Verträge (OpenAPI/springdoc, generierte Clients, Contract Diffing in CI) und halten Sie diese rückwärtskompatibel.
  • Schreiben Sie sinnvolle Tests auf allen Ebenen: JUnit 5, AssertJ, Mockito, ArchUnit, Testcontainer (Postgres + LocalStack), WireMock, REST Assured.
  • Eigene Services in der Produktion: Datadog APM/RUM, Micrometer/OpenTelemetry, Structured JSON Logging und On-Call-Teilnahme.
  • Versand durch GitHub Actions-Pipelines mit SonarQube-Qualitätstoren, JaCoCo-Abdeckung, CycloneDX-SBOMs und strenger Gradle-Abhängigkeitssperrung.
  • Überprüfen Sie den Code von Peers und nehmen Sie an Architekturentscheidungen teil - nicht nur Implementierung von Tickets.

Muss haben (4-5 Jahre)

  • 4+ Jahre professionelle JVM-Entwicklung, mit jüngsten Arbeiten an Java 17/21 und Spring Boot.
  • Solides Verständnis von OAuth 2.0, OIDC, JWT und SAML - Sie können Autorisierungscode + PKCE, Tokenaustausch und Aktualisierung der Tokenrotation erklären, ohne sie nachzuschlagen.
  • Hands-on relationale Datenbankarbeit: Schema-Design, Indexierung, Abfrage-Tuning und versionierte Migrationen (Liquibase oder Flyway).
  • Praktische AWS erleben die Ausführung von Produktions-Workloads (Messaging, Storage, Secrets, IAM).
  • Docker und Container-basierte lokale Entwicklung
  • Komfort mit Docker Compose und Testcontainern.
  • Starke automatisierte Testdisziplin - Sie behandeln Tests als Teil des Lieferumfangs, nicht als nachträglicher Einfall.
  • Git-basierter trunk/feature-branch Workflow, CI/CD-Pipelines und Code-Review als tägliche Gewohnheit.
  • Klare schriftliche Kommunikation in Englisch
  • Fähigkeit, Entscheidungen und Kompromisse zu dokumentieren.

Stark bevorzugt

  • Direct Keycloak Erfahrung (Custom Provider, SPIs, Admin Client, Theming) oder vergleichbare IdP Arbeit (Auth0, Gigya, Okta, ForgeRock).
  • Gradle (Kotlin DSL) in einem Multimodul / Platform-BOM Setup.
  • React 18 + TypeScript mit Vite - genug, um einen vollständigen vertikalen Schnitt durch die Benutzeroberfläche zu besitzen.
  • Node.js/Express Services in TypeScript.
  • Kubernetes und Helm
  • Terraform für Infrastruktur und IdP-Konfiguration als Code.
  • Observability Practice: Dashboards, SLOs, Alerting und Debugging verteilter Traces.
  • Erfahrung in einem regulierten Umfeld (Gesundheitswesen / Biowissenschaften, GxP, HIPAA / GDPR) - Datenschutz ist hier ein erstklassiges Anliegen.

Nizza zu haben

  • Python (Tooling/Automatisierung), Ruff/pytest.
  • Playwright oder Cypress End-to-End-Tests; visuelle Regressionstests.
  • Leistungs-/Lastprüfung (k6, JMeter).
  • Applikationssicherheit Hintergrund: OWASP Top 10, SAST/DAST, Dependency und SBOM Hygiene.
